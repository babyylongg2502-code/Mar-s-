# Website BracesCare

Website tĩnh viết bằng HTML, CSS và JavaScript thuần.

## Cấu trúc

```
bracescare-website/
├── index.html   Khung trang, thẻ SEO, header, footer
├── style.css    Toàn bộ giao diện
├── script.js    Nội dung các trang, dữ liệu, định tuyến
└── assets/
    └── images/  Ảnh đã tách khỏi code (tên file trùng khóa trong biến IMG của script.js)
```

## Chạy thử

Mở `index.html` bằng trình duyệt, hoặc chạy `python -m http.server 8000` trong thư mục này rồi vào `http://localhost:8000`.
